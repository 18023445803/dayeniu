## 🔑 核心线索

- **状态机视角**：C 程序 / ISA / 数字电路三者都是状态机，编译与 CPU 设计是状态机之间的翻译与实现
- **实例化 + 连线**：HDL 代码要能在头脑中映射成电路结构
- **STFW / RTFM / RTFSC**：独立解决问题三板斧
