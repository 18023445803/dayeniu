# # E2 C语言程序设计
虽然"一生一芯"的学习目标是设计处理器芯片, 但由于处理器芯片有别于其他芯片, 你还是会频繁地与软件程序打交道. 因此, 理解程序如何在处理器上运行, 才能明白如何让程序在处理器上运行得更好.
C语言是帮助大家理解这个问题的不二选择. 另一方面, 考虑到参加"一生一芯"的不少同学就读的是非计算机专业, C语言对大家来说学习的门槛也比较低. 大家需要掌握如下内容: 递归, 指针, 链表, 并且能够独立写出正确的程序(而不是在百度上搜一个所谓的示例代码).

####  通过线上网站学习C语言
你之前应该已经使用过Compiler Explorer在新窗口中打开这个在线网站来运行C程序了, 现在你将要系统地学习C语言程序设计, 并通过这个在线网站来完成一些编程作业.
具体地, 你需要学习Linux C编程一站式学习在新窗口中打开中的 第1~9章, 第11~16章, 第21章, 第23~25章, 以及第26章第1节(即"链表"). 你需要完成所有习题, 并在Compiler Explorer中测试你的程序是否正确.
此外, 你需要在正确运行程序之后, 把相应的程序代码保存到本地, 一方面可以把这些程序作为你的作业保留下来, 另一方面, 后面在安装Linux后, 我们会要求你再次运行其中的一些代码.
如果你对自己的C语言水平很有自信, 能够在不参考其他代码的情况下, 能独立编写一个链表程序并调试正确, 你可以跳过这部分学习. 如果你没有完整学习过C语言程序设计, 或者已经遗忘得差不多, 我们非常不建议你跳过这部分学习.

####  另外推荐一些C语言学习资料

- The C programming language (2nd Edition)在新窗口中打开: 真正的C语言之父是这本书的作者Dennis M. Ritchie在新窗口中打开, 而不是谭浩强
- C Coding Standard在新窗口中打开
- SEI CERT C Coding Standard在新窗口中打开
- Learn C the hard way 中文版在新窗口中打开
